## Description

Spendly is a frontend expense tracker for students and individuals who want to record income and expenses, review spending by month and category, set budgets, and keep bill reminders.

## Target users and objectives

Spendly is intended for students and individuals who want a simple way to keep track of everyday finances.

The project aims to help users record transactions, review their spending, manage category budgets, and remember upcoming bills.

## Features

- Add and edit income and expense transactions.
- Validate transaction form entries and show feedback.
- Search transaction records and view attached receipt images.
- View balances, monthly summaries, and spending charts.
- Set or remove category budgets.
- Add, edit, and delete bill reminders.
- Save app data in the browser using local storage.
- Load sample data or clear saved data.

## How to open and use Spendly

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a web browser, or visit the deployed site once GitHub Pages is working.
3. Use the navigation to open Home, Receipts, Statistics, and Reminders.
4. Select **Add transaction** to record income or an expense.
5. Use Statistics to review spending and set category budgets.
6. Keep an internet connection available so Bootstrap and the Montserrat font can load from their CDNs.

## Known limitations

- Data is stored in the current browser on the current device. It does not sync to an account or server.
- Reminders appear inside the app; they do not send phone or desktop notifications.
- Bootstrap and the Montserrat font load from online CDNs and need an internet connection.
